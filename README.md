# City Library WordPress Theme (lib33theme)

Современная адаптивная тема WordPress для городской библиотеки с интеграцией Tailwind CSS, умным полнотекстовым живым поиском и виртуальным библиотекарем.

## Особенности темы

- **Дизайн и адаптивность:** Полностью адаптивный интерфейс (Desktop, Tablet, Mobile) с чистой типографикой и аккуратными карточками.
- **Живой поиск (Live Search):**
  - Модальное окно поиска с размытием фона и плавной анимацией.
  - Контекстные инлайн-подсказки (Ghost Autocomplete) в стиле Google/Яндекс с автодополнением по <kbd>Tab</kbd> или <kbd>→</kbd>.
  - Фильтрация стоп-слов и поиск точных фраз в заголовках и текстах записей.
  - Отображение контекстных сниппетов с подсветкой совпадений `<mark>`.
  - Категоризация результатов (книги, события, новости, филиалы, страницы).
- **Виртуальный библиотекарь:** Интерактивный AI-помощник читателя.
- **Интерактивные компоненты:** Доступная навигация, поддержка клавиатуры (<kbd>Ctrl+K</kbd> / <kbd>Cmd+K</kbd>, <kbd>Esc</kbd>), карточки филиалов и афиша событий.

## Структура проекта

```text
├── 404.php                 # Шаблон страницы ошибки 404
├── archive.php             # Шаблон архивов
├── assets/                 # Шрифты, изображения, медиа
├── css/                    # Стили темы и модального окна поиска
├── footer.php              # Подвал сайта
├── functions.php           # Инициализация темы, хуки, стили и скрипты
├── header.php              # Шапка сайта и меню
├── inc/                    # Модули (live-search.php, virtual-librarian.php и др.)
├── index.php               # Основной шаблон
├── js/                     # Скрипты (поиск, AI-чат, навигация)
├── page.php                # Шаблон статичной страницы
├── screenshot.png          # Превью темы для консоли WordPress
├── search.php              # Шаблон страницы результатов поиска
├── searchform.php          # Форма поиска
├── sidebar.php             # Сайдбар
├── single.php              # Шаблон отдельной записи
├── style.css               # Главный файл стилей темы
└── template-parts/         # Части шаблонов (search-modal.php и др.)
```

## Установка

1. Скопируйте папку темы в директорию `wp-content/themes/` вашей установки WordPress.
2. В панели управления WordPress перейдите в **Внешний вид → Темы** и активируйте **City Library**.
